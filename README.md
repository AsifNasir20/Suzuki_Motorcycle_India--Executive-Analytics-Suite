# 🏍️ Suzuki Motorcycle Sales Dashboard

An interactive **Power BI dashboard** designed to analyze Suzuki motorcycle sales performance across **models, regions, and time periods**, with dynamic KPIs, trend analysis, and interactive navigation.

## ✨ Key Features

* 📊 Dynamic KPI tracking
* 📈 Year-over-Year (YoY) & Month-over-Month (MoM) analysis
* 🏍️ Model-wise sales performance analysis
* 🌍 Regional sales analysis
* 📅 Dynamic sales trend analysis
* 🔄 Interactive page navigation
* 🧮 DAX-powered calculations

## 💡 Key Insights

* 🏍️ Compared sales performance across different motorcycle models.
* 🌍 Analyzed sales variations across regions.
* 📈 Evaluated sales trends using YoY and MoM analysis.
* 📊 Used dynamic KPIs and interactive visuals to support performance analysis.
